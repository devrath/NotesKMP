Design system

Marky is a pen and a highlighter. Text is cobalt ink on cool paper, and a single marker-yellow swipe is the one loud element: the wordmark, the create button and search matches. Everything else stays quiet so the writing leads.

Tokens live in assets/tokens.css and map one-to-one onto the Compose theme (MarkyTheme). Each component below is drawn by the same code as the screen mockups.

Principles

Writing leads

  • No chrome competes with text: flat surfaces, hairline outlines, no decorative shadows.
  • One tap to a focused cursor.

Yellow means “this is the thing”

  • Marker yellow is reserved for the create action, the brand mark and search matches.
  • It always carries ink-colored content, never white.

Native where it counts

  • Platform fonts, navigation, menus, dialogs, pickers and share flows.
  • Shared layout, color, icons and copy everywhere else.

Never color alone

  • Pins are icons, highlights are background plus bold, done items carry a check.
  • Every pair passes WCAG 2.2 AA in both themes (checked live below).

Color

Five base colors. Everything in the app is a role that points at one of them, so dark mode is a remap rather than a second design. On Android 12+, dynamic color may replace the cobalt roles as long as these contrast checks still pass; marker yellow stays.

Spacing, shape and motion

A 4-point grid. Screen gutters are 20 for reading text and 12–16 for lists. Corner radius grows with the size of the surface.

Icons

One outlined set on a 24 grid with a 1.75 stroke: 24 dp on Android, 22 pt on iOS. Icon-only buttons always carry an accessible name, shown as a tooltip on long-press.

Components

Shown for both platforms where they differ. Touch targets are at least 48 × 48 dp and 44 × 44 pt even when the visible shape is smaller.

Markdown: editor and preview

The same note in both modes. The editor highlights syntax lightly but never changes the text. The preview uses 1.5× line height, about 70 characters per line at most, and sideways-scrolling code.

Copy rules

Sentence case, plain verbs“New note”, “Export as Markdown”, “Copy link”
Same word through a flow“Import” → “Imported “Ideas””; “Export” → “Exported “Weekly plan.md””
Errors say what and why“This file is too large to import (max 5 MB)”; never just “Error”
Empty states point to an action“No notes yet. Write your first note, or import a Markdown file.”
No confirmation chatterNo “Saved!” toast; a quiet status only
