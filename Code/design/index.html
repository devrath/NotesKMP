Designs for Marky

A local-first Markdown notes app for Android and iOS: write in Markdown, read it formatted, find any note in seconds. Phone only, no tablet or web layouts.

These pages draw every screen and state from requirements/marky-feature-specification.md, plus the design system they're built from. Open them straight from disk; nothing needs a server.

Design systemColor roles with live contrast checks, type, spacing, icons, components, Markdown styling. Android screens16 screens and states in Material 3, light and dark. iOS screensThe same 16 screens and states with iOS navigation, menus, alerts and share sheet.
